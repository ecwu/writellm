# ADR 001: Checkpoint 19.5 Boundary Freeze

Status: accepted
Date: 2026-07-16

## Decision

WriteLLM persists only resumable external/import state and rebuildable index
work. The durable job types are `mineru_parse`, `normalize_parse_revision`,
`build_index_generation`, `build_embedding_generation`, `remove_index_item`,
`rebuild_index`, and `artifact_cleanup`. Interactive search, query embedding,
reranking, provider probes, manuscript mutations, and Agent turns use
request-scoped cancellation and concurrency limits.

MinerU signed and download URLs exist only in the current background-worker
request. A project persists `remote_task_id`, provider state, timestamps,
result fingerprints, download state, and retry metadata. Reopen recovery polls
the remote task to obtain a fresh URL.

The first Agent surface is four read tools (`get_writing_context`,
`read_section`, `search_knowledge`, `read_citations`) and three proposal tools
(`propose_brief_update`, `propose_outline_patch`, `propose_section_patch`). Its
initial project persistence is limited to `agent_sessions`, `agent_runs`,
`agent_events`, `mutation_proposals`, and `model_requests`.

## Consequences

Old Phase verification mentioning encrypted MinerU capabilities, broad queues,
the old Agent schema, or provider-specific worker roles remains historical
evidence only. Migrations must safely discard or normalize obsolete recovery
state without attempting to decrypt it.
