WriteLLM 0.2026.10.5 makes image generation sources configurable.

Settings → Image API now lists image sources the way Agent providers work.
You can add several Google Gemini, Google Vertex AI, OpenAI Images, or xAI sources, including several accounts of one type.
OpenAI Images and xAI sources accept a custom Base URL for compatible gateways. Changing the endpoint removes the stored key.
Each source lists its built-in models. You can add model IDs, declare 2K support, and turn any model off.
One default image model applies everywhere. Agent details can choose a different image model for one conversation, and forks keep that choice.
If the chosen source or model is removed, disabled, or not signed in, generation stops with an error. It never switches to another model.

Existing image settings upgrade in place. Saved keys and the active source's model are kept, and that model becomes the default.
Projects upgrade with a verified backup before the new conversation setting is added.

Local runtime acceptance covers macOS arm64. Other platform runtime acceptance remains outstanding.
The complete package gate passes all ten stages in 261.3 seconds with one App build.
It covers all twelve packaged runtime scenarios and all 45 packaged interaction scenarios, with zero retries or skips.
The DMG and ZIP pass structure and checksum checks.
Hosted CI builds and inspects Windows x64, macOS arm64, macOS x64, and Linux x64 packages without runtime tests.
