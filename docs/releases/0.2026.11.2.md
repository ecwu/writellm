WriteLLM 0.2026.11.2 adds voice input and model discovery, improves project recovery, and fixes reliability issues across writing and research workflows.

## Feature

- Voice input in the Agent composer, with realtime and file transcription, a live waveform, and editable results before sending. Cancelling preserves the original draft.
- Multiple speech sources with independent credentials, models, and transcription modes. Select the active source in Settings without adding another selector to the conversation.
- Image and speech model discovery from provider APIs and models.dev. Search available models or enter an ID manually; connection tests remain optional.
- Project recovery from the launcher, with clear failure reasons and recovery actions. Rebuild a missing project manifest in place or open a repaired copy.

## Bug Fix

- Fix OpenAI ChatGPT sign-in compatibility with Pi.
- Fix Agent message-queue races during Steer, Follow-up, Stop, and run completion. Late replies no longer continue stopped runs or target replacement workers.
- Fix Notebook cancellation during preparation and source changes during a conversation. Temporary index outages preserve confirmed context, and oversized replies retain the last valid text.
- Fix duplicate embedding refreshes, interrupted index rebuilds, and outdated search results after sources change. Search recovers when its worker restarts.
- Fix heading filters for encoded text and source locations for split search passages.
- Fix project close retries, stale-lock recovery, and interrupted checkpoint restores. Restores retain project locks and history through recovery.
- Fix save and export consistency when edits overlap. Exported text and citations use the same manuscript snapshot, and identical save retries can restore missing section files.
- Fix native-menu layout commands that disappear during a layout update.

## Enhance

- A shared Agent and Notebook model picker combines provider filters, model search, and reasoning-level selection.
- Save status and section actions move to the bottom status bar, with centered controls for Outline, section selection, and Agent.
- Align panel headers and improve toolbar, sidebar, Settings, and dialog layouts, including clipped controls and status indicators.
- Reduce duplicate editor refreshes after Agent changes, and reduce repeated work during indexing, search, and source mapping.
- Update Pi AI and Agent Core to 1.5.2, Electron to 45.2.3, and the editor, math-rendering, and supporting libraries.
