This release stabilizes the desktop workbench and improves navigation and writing controls.

- Closing a docked tool gives freed space to the main content area while preserving surviving sidebar widths. Pointer and keyboard resizing remain available, and closing the final content tab keeps an empty content surface.
- Tool close controls are consolidated in dock tabs. Opening Manuscript from an empty workbench restores Outline without an action error.
- macOS uses native application menus. Native Layout checks stay aligned with open panels when a save conflict prevents closing a page. Windows and Linux retain their in-window menus.
- Section titles retain their intended desktop typography.
- The curated Writing Skill catalog adds Chinese and English Anti-Defensive Writing entries pinned to reviewed upstream content. Third-party bodies are installed explicitly, not bundled.

Local validation: 1,627 Electron-hosted tests passed, with three intentional benchmark skips. The subsequent native-menu fix passed all 10 affected tests. Complete macOS arm64 package acceptance passed in 258.2 seconds, including 12 smoke scenarios, all 43 packaged E2E scenarios with zero retries/skips, and DMG/ZIP inspection. The initial package attempt exposed one menu-state defect and four fixture/focus problems; those were corrected before the passing final gate.

Runtime evidence is macOS arm64 only. Windows, Linux and macOS Intel receive native build and package-inventory checks, not hosted runtime tests. Physical system-IME candidate selection remains unverified. Local host Node 26.10.0 is outside the declared Node 24 range; native tests use Electron 43.4.1 / ABI 148 and pnpm 11.17.0. Hosted builds use declared Node 24.15.0.
